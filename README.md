# Clínica Ghisolfi — Sistema de Gestão

## Como publicar no Vercel

### Passo 1 — Instalar o Node.js
Baixe em: https://nodejs.org (versão LTS)

### Passo 2 — Subir para o GitHub
1. Acesse github.com e clique em **New repository**
2. Nome: `clinica-ghisolfi`
3. Deixe **Private** (privado)
4. Clique em **Create repository**
5. Siga as instruções para fazer upload da pasta

### Passo 3 — Publicar no Vercel
1. Acesse vercel.com e clique em **Add New Project**
2. Conecte seu GitHub e selecione o repositório `clinica-ghisolfi`
3. Clique em **Deploy**
4. Aguarde ~2 minutos — seu site estará no ar!
